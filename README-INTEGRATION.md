# PDM CI — Page Services

## Installation

Copier uniquement ces fichiers dans le projet PDM CI existant :

- `pages/services.html`
- `assets/css/services.css`
- `assets/js/services.js`

## Important

Cette page utilise le `assets/css/style.css` et le `assets/js/main.js` déjà présents
dans ta V0.2. Ne pas les remplacer.

Le menu utilise les liens :

- `../index.html`
- `catalogue.html`
- `services.html`
- `showrooms.html`
- `actualites.html`
- `contact.html`
- `demande-devis.html`

Les données de services sont fictives pour la Phase 1 et sont regroupées dans
`assets/js/services.js`, ce qui facilitera leur remplacement par une base de
données en Phase 2.

La page contient également la même structure de fenêtre de confidentialité
que les autres pages.
